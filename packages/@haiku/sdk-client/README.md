# @haiku/sdk-client

SDK client for Haiku's public APIs.

## Usage

```javascript
import {inkstone} from '@haiku/sdk-client'
```

## Development

This package uses [`tsdown`](https://github.com/rolldown/tsdown) for TypeScript compilation.

- Build: `pnpm compile`
- Watch mode: `pnpm develop` (runs `tsdown --watch`)
