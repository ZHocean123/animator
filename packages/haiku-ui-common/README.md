# ui-common

Common UI components for Haiku projects.

## Setup

After cloning the repo:

```
$ pnpm install
$ pnpm global add @storybook/cli
```

Then develop with:

```
$ pnpm develop
```

## Tests

Run the tests with:

```
$ pnpm test
```

## Linting

Lint with:

```
$ pnpm lint
```

Autofix lint errors with:

```
$ pnpm fix
```
